Análise Exploratória e Visualização de Dados de E-commerce

Este repositório contém scripts para análise e visualização de dados de um dataset de e-commerce.  
O objetivo é explorar as relações entre preços e avaliações (notas) dos produtos, utilizando gráficos diversos para entender melhor o comportamento dos dados.

A análise exploratória mostrou que a maior parte dos produtos possui avaliações muito positivas, concentradas acima de 4 estrelas. Os preços apresentam distribuição assimétrica, com predominância de produtos de baixo e médio valor e poucos itens significativamente mais caros. A correlação entre preço e nota foi praticamente nula (-0,03), indicando que produtos mais caros não necessariamente recebem melhores avaliações. Além disso, observou-se grande concentração de avaliações em poucos produtos, sugerindo diferenças relevantes de popularidade dentro do marketplace.
